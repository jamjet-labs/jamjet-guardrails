# Hidden-Unicode scanners on one corpus

Generated by `benchmarks/unicode-scanners/render.py` from `results/measurements.json`.
Do not edit by hand: `tests/test_unicode_scanner_benchmark.py` re-renders this file and
fails on any difference.

Measured on **2026-10-10** on Darwin arm64, Python 3.12.4 (Unicode 15.0.0), Node v26.10.0. Network access was denied to every scanner by the operating system sandbox while it ran.

The corpus is 54 files: 27 carry content a reviewer cannot see and should be flagged, and 27 are hard negatives, ordinary writing that uses invisible or format characters on purpose and should pass. Every case is in [`corpus.jsonl`](corpus.jsonl), built from code points by [`build_corpus.py`](build_corpus.py).

## Read this before the numbers

- **We wrote this corpus, and we also wrote one of the scanners.** The cases were written after `jamjet-guardrails`' detector existed, by people who knew what it catches. Read every number for it as self-graded. The third-party rows are scored on the same files by the same harness, and nothing here was tuned per tool.
- **Labels are a judgement:** `flag` where a file carries text that renders as something other than what an agent reads, `pass` where every unusual character is ordinary writing. Some tools treat a stray joiner or a non-breaking space as worth a failed build on purpose; on this corpus that scores as a false positive.
- **Defaults only, one decision per file, read from the exit code.** Several scanners report more than they fail on (ghostchars and hidden-content-scan both have warning levels that exit 0). Only what fails the step is scored here.
- **The `encoded` family favours us.** Three of its four cases are JSON escapes in agent configuration, which `jamjet-guardrails scan` decodes and the others do not claim to. They were added at the same time as that decoding.
- **The naive row is a rule, not Snyk's scanner.** It flags any Cf or Cc character, the rule Snyk Agent Scan's W021 issue code describes. Snyk's scanner itself was not run.

A miss is a `flag` case the scanner passed; a false positive is a `pass` case it flagged. Each case id is a line in `corpus.jsonl`.

### jamjet-guardrails scan

5 missed, 2 false positives.

- Missed: `vs-07`, one selector after each visible letter. Already known: disclosed in corpora/NOTICE.md: one selector after each character that is none of the blank covers.

- Missed: `enc-04`, tag characters written as HTML numeric references, invisible once the markdown renders.
- False positive: `neg-cjk-ivs-stray-vs16`, an IVS followed by a stray VS16, which a careless editor writes. Already known: disclosed in corpora/NOTICE.md as inj-0177.
- False positive: `neg-isolate-across-lines`, FSI ... PDI around a two-line value. Already known: disclosed in corpora/NOTICE.md as inj-0091.
